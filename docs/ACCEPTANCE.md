## 没有处理、需要作者决定的项
1. **手机端正文 15px → 16px、点击区域 ≥44px**：会改变每一章的排版，需要作者批准。
2. **`--muted` 对比度**：把 #8c8c86 调深一档（例如 #6f6f69，约 4.9:1）可通过对比度审计，但会让所有灰字变深，视觉有变化。
3. **06 章标题层级**：把那个 h4 改成 h3 可修复；`.step6 h4` 的样式是按标签写的，改标签要同步改样式选择器。
4. **01 导语用宋体**与「作者观点用黑体」的规则冲突。
5. **字号 / 间距 token**：要做的话需要先定一套 token，再逐批替换并比对。

# 照片页 · 开发说明（第二阶段）

> 在现有 Product Lab 站点上新增一栏「照片」。**视觉与交互以 `reference/photo.html` 为准**，不要重新设计。不引入新的技术栈，沿用站里的 Astro、vanilla CSS、tokens 和已有的放大（lightbox）脚本。

## 0. 先做什么

1. 在浏览器里打开 `reference/photo.html`，1280 和 390 宽各看一遍，把「Order / Entropy」切换、搜索、点开放大都操作一遍。
2. 先列出「参考页与现有站点的差异」（页眉、字体、宽度、tokens）发给作者，再动手。
3. 在新分支上做，完成后截图对照参考页，提交说明写偏差。不要合并、不要推送，等作者确认。

## 1. 范围

- 导航新增「照片」，排在「文章」之后。页面路径 `/photos/`。
- 首页不放照片区块。
- 不做：评论、点赞、标签页、分享按钮、后台、数据库、动画库。

## 2. 内容与数据

作者把素材放进 `src/content/photos/`（图片、短片），并维护一份 `photos.yaml`（模板见 `photos.yaml`）。每条：

| 字段 | 必填 | 说明 |
|---|---|---|
| `file` | 是 | 文件名，图片或短片 |
| `place` | 是 | 地点，显示在图上方，也参与搜索 |
| `title` | 否 | 一句话标题，显示在图下方；没有就不显示 |
| `date` | 是 | `YYYY-MM-DD`，页面上只显示到月（如 `2026.10`），日只用于排序 |
| `tags` | 否 | 主题词，如 下雨、夜晚、海边，用于搜索 |
| `poster` | 短片必填 | 短片的静态首帧 |
| `order` | 否 | 手动排序的整数，数字小的靠前 |

用 Content Collections 的 zod 校验。

**排序：** 有 `order` 的先排（数字从小到大），其余按 `date` 从新到旧。Order 与 Entropy 两种排布、搜索筛选都使用同一个顺序；筛选只让不匹配的变淡，不改变位置。

## 3. 图片与短片处理

- 用 `astro:assets` 生成多种宽度的 webp，原图只在放大时加载，首屏以外懒加载。
- **构建时去掉 EXIF，尤其是 GPS 位置和相机序列号。** 这是硬性要求。
- 照片保持原始比例，不做裁切。
- 短片：`<video muted loop playsinline preload="none" poster="…">`，同时提供 mp4（H.264）和 webm。每段 ≤ 4 秒、≤ 1MB；整页不超过 3 段。
- 短片只在进入视口时播放，滚出就暂停（IntersectionObserver）。系统开了「减少动态效果」时只显示 poster。
- 不使用 GIF。

## 4. 页面结构与两种排布

页眉、页脚、字体、宽度沿用站里。页面标题「照片」用站里其他页面标题的同一套样式。

顶部：页面标题 → 搜索框 → 示例词（见 §5）→ 一条细线，线右侧是 **Order / Entropy** 切换。

**Order**：所有素材缩成小方块，6 列（手机 4 列），最宽 640px，没有图注。鼠标放上去方块上浮 4px。
**Entropy**：错落图集，最宽 1000px，12 栏网格。每张保持自己的比例。

- 默认进入 Order。第一次向下滚动、点击任意方块、或点击 Entropy，切到 Entropy。切换用 FLIP 动画（位置和尺寸），每张延迟 28ms，总时长 0.7s。参考页里有完整实现，照搬。
- **Entropy 的位置不要手写。** 定义一组循环的版式（参考页里的 `cs / sp / row / mt` 是 12 张的样例），按顺序循环使用，让任意数量的照片都能排出错落的节奏：小图、大图、竖图交替，起点高低不同。
- 手机上 Entropy 改为单列，宽度交替为 100%、72% 靠右、60%，保持错落。
- 照片和短片 **一律直角，不加圆角、不加边框、不加阴影**。

## 5. 搜索

输入框是胶囊形，黑色 1.5px 边框，输入时边框变蓝，**不加外发光**。右侧有一个 36px 黑色圆形箭头按钮：没输入时隐藏，有输入时淡入，输入框有焦点时变蓝。回车也可提交。输入时 260ms 后自动筛选。

输入框的占位字自动打字、删除，轮流显示示例词；输入框获得焦点或有内容时停止。

示例词（胶囊）由作者提供，默认：下雨的夜晚、安静的清晨、去年的海边、京都。

筛选规则（纯前端，无 AI）：
- 匹配 **地点、标题、tags**（地点和年月是页面上看得见的，tags 是看不见的主题词）（tags 有同义词表，见参考页的 `ALIAS`）。
- 识别日期：`去年`、`今年`、`2026`、`3月`、`三月`；日期条件和文字条件同时成立才算匹配。
- 不匹配的照片变淡（透明度 .14、灰度），**不删除、不重排**。
- 一个只给屏幕阅读器读的元素播报「N 张符合」，页面上不显示数量。

## 6. 图注

Entropy 里，每张照片 **上方** 一行小字：`地点　2026.10`（13px，`--ink-2`，数字等宽），地点在前、年月在后，间距 14px。**下方** 一行标题（13px，`--muted`）；没有标题就不渲染这一行。不再有悬停显示，手机和电脑一致。Order（印样）里没有文字。

## 7. 放大（Lightbox）

复用站里现有的放大脚本，扩展为支持短片：
- 点击 Entropy 里的任意照片或短片打开。短片在放大里继续静音循环，**没有控制条**。
- 方向键切换（只在当前未被筛掉的素材里切换），Esc 关闭，焦点回到原位，打开时锁定页面滚动，Tab 只在放大窗口内循环。
- 下方居中显示标题、地点和年月（没有标题就只显示地点和年月）。
- 关闭按钮、上一张、下一张 ≥ 44px。

## 8. 验收

- [ ] 页面与 `reference/photo.html` 在 1280、390 两个宽度下视觉一致，没有横向滚动
- [ ] 素材里没有 EXIF（尤其 GPS）
- [ ] 颜色、字号、间距来自 tokens，没有零散硬编码
- [ ] 全部素材直角，无阴影，无发光
- [ ] 键盘可以完整操作搜索、切换、放大
- [ ] 减少动态效果时：切换无动画、短片只显示 poster、占位打字停止
- [ ] 深色模式文字可读，照片不反色
- [ ] Lighthouse（手机）性能 ≥90、可访问性 ≥95
- [ ] 不请求境外字体或 CDN

## 9. 参考页里是示例的部分

`reference/photo.html` 中的色块代表照片，带流光的方块代表短片，地点、标题、日期、标签都是示例。真实站里全部由 `photos.yaml` 提供。
